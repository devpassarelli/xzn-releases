# XzN Launcher: downloads

Instaladores do **XzN Launcher** e das versões personalizadas dele, para jogar várias contas do Pokéidle.io numa janela só.
Este repositório só guarda os instaladores; o app instalado busca as atualizações aqui sozinho.

## Como instalar

1. Abra a [**última versão**](https://github.com/devpassarelli/xzn-releases/releases/latest) e, em *Assets*, baixe o instalador da sua versão:
   - `XzN-Launcher-Setup-<versão>.exe`: **XzN Launcher**
   - `Macacao-Rei-Setup-<versão>.exe`: **MACACÃO REI 🦍**
2. Dê dois cliques. Ele instala sozinho, sem pedir administrador, e cria um atalho na Área de Trabalho.
3. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o app não tem certificado pago).

Pronto: daqui para frente o app **se atualiza sozinho**. Quando sai uma versão nova, ele baixa em segundo plano e mostra o botão **Atualizar** na barra de cima. Logins e configurações são mantidos.

Não precisa de conta no GitHub para baixar.
